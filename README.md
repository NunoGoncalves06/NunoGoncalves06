## <img src="assets/icon-folder.svg" width="20" height="20" alt=""> Projects

### Three-site enterprise network

The CCNA 3 final project: a company network across a headquarters and two branches, built by a team on real Cisco routers, switches and access points. It got the maximum score.

Cisco IOS, OSPF, IPsec VPN, ACLs, NAT, port security and Ansible. The repository is private.

### AISafe

A flight control management prototype: a flight-plan language parsed with ANTLR, a simulation engine in C, and user roles with security clearances.

Worked on every part of the project with my team, including designing the user roles and clearance levels and implementing the permission checks. The repository is private, so there is no link.

### IoT sensor node

An ESP32-C6 board with a distance sensor publishing readings over MQTT, in its design phase with my group.

### [SpotCast](https://github.com/NunoGoncalves06/SpotCast)

An Android app for Mobile Application Development at Aarhus University. Save outdoor spots and get a Go, Maybe or Skip for each activity from that spot's forecast, with unit tests for the rules and the API clients.

### [Wakecast](https://github.com/NunoGoncalves06/Wakecast)

An alarm that reads you a morning briefing when you dismiss it: the weather, your calendar, your to-dos and the news. It runs entirely on the phone, with no account and no tracking.
